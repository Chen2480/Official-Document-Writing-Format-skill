# 公文报告 1.0 —— 党政公文与央企正式文稿写作 Skill

一个面向党政机关、中央企业综合文字工作场景的 AI 写作技能（Skill）。扮演在机关长期从事综合文字工作的"资深笔杆子"，内置**文件式、便函式、纪要式**三种公文版式的强制排版规范，可完成讲话稿、工作报告、请示报告、通知通报、发言稿、宣传稿、评论文章、调研文章、汇报材料、党建材料、会议纪要等文稿的起草、改写与润色。

## 功能特性

- **文种全覆盖**：法定公文（请示、报告、通知、通报、批复、函、纪要等）、事务文书（总结、方案、调研、汇报、简报）、会议材料（讲话稿、表态发言、经验材料）、宣传类文稿。
- **三种版式内置**：
  - 文件式（以行政上行文为例，含红头、发文字号、签发人、红线、版记）；
  - 便函式（办公室通知，文武线、不编发文字号、首页无页码）；
  - 纪要式（专题会议纪要，纪要编号、发文单位、签发日期）。
- **强制排版规范**：A4 页面、页边距（上3.7/下3.5/内2.8/外2.6 cm）、每页22行×28字、行距固定值28磅、三号仿宋GB2312正文、二号方正小标宋标题、五层结构标题字体、全角标点、附件与署名日期印章规则、版记与页码规则等。
- **权威来源检索**：支持检索中国政府网、新华网、人民网、求是网等权威来源，政策表述、引文数据不杜撰。
- **去 AI 化审稿**：内置去 AI 味排查清单，规避意义膨胀、假深刻、模糊主体、规则三连、万能结尾等典型问题。
- **两轮审稿 + 百分制自检**：公文规范审与去 AI 味审，按评分表自检后方可交付。

## 安装方法

1. 下载本仓库（或 Release 中的压缩包）。
2. 将整个 `公文报告1.0` 文件夹放入 AI 助手的 Skill 目录：
   - 用户自定义技能目录：`...\.doubao\agent_mode\workspace\.user_skills\`
   - 或系统技能目录：`...\.doubao\agent_mode\workspace\.skills\`
3. 重启 / 刷新助手，技能即被自动识别。

## 使用方法

直接用自然语言下达任务即可，例如：

- "按文件式公文写一份关于 XX 工作的请示"
- "帮我拟一份办公室关于开展 XX 专项检查的通知（便函式）"
- "整理一份 XX 专题会议纪要"
- "把这篇工作总结改成《人民日报》风格，2000 字以内"
- "以新人视角写一份入职表态发言稿"

**默认规则**：用户未提出特殊格式要求时，一切正式公文严格按 `references/gongwen-geshi.md` 的版式与排版输出；用户另有要求时，以用户要求为准。

## 工作流程

明确任务 → 判定版式 → 检索依据 → 提取事实 → 确定文种与框架 → 起草正文 → 两轮审稿（公文规范审 + 去 AI 味审）→ 评分交付。

## 适配说明

- 公文排版参数依据单位《公文格式要求》及文件式、便函式、纪要式标注版模板整理；不同单位的具体参数（如红头机关名称、代字、字体授权）可能存在差异，使用前请按本单位规定替换。
- `方正小标宋`、`仿宋GB2312`、`楷体GB2312` 等字体需在本机 / WPS Office 中安装后方可正常显示。
